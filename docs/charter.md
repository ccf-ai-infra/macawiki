# Macawiki v0.1 charter

## Purpose

Build a small, auditable MXMACA knowledge base that helps humans and AI agents retrieve version-scoped evidence and refuses unsupported conclusions.

## Approved v0.1 scope

- Repository structure and governance rules.
- Dependency-free schema, validation, query, page-read, grep, index, and status tools.
- A minimal set of public source records and clearly non-verified synthesis pages.
- No bulk ingestion, external writes, hardware benchmarking, or upstream automation.

## Proposed next review

Maintainers should review language policy, source/licensing policy, initial hardware and MXMACA versions, and Tier 1 repositories before expanding the corpus.
