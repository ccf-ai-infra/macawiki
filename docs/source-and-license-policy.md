# Source and license policy

1. Include public URLs and original summaries by default.
2. Do not store login-only, confidential, marked-restricted, or license-unclear document bodies.
3. Copy code or attachments only after recording an applicable license, an immutable ref, retrieval date, and provenance manifest.
4. Use the smallest excerpt necessary and retain attribution.
5. Mark license uncertainty as `unknown` and defer the asset.
6. Never present a community claim as an official MXMACA guarantee.
7. Treat repository license and embedded third-party file licenses independently.
