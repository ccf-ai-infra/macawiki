# Macawiki topic map

Read this file before answering broad MXMACA questions.

## Navigation

- Installation and first program: query `recipe`, `quick-start`, or `programming-model`.
- Compiler and runtime: filter by components such as `mxcc` or `mxmaca-runtime`.
- Profiling and diagnosis: filter by `mcprofiler`, `mctracer`, `diagnostics`, or a symptom tag.
- Kernel optimization: query `kernel`, `performance`, `roofline`, `memory`, or an operator name.
- Framework adaptation: filter by `mcpytorch`, `mctriton`, `vllm-metax`, or `mctilelang`.
- Compatibility: always add hardware and MXMACA version filters when known.

## Evidence priority

Use official release notes and API/programming documents first, then public upstream code pinned to a commit, official examples, reproducible experiments, and finally community material. Treat missing scope as `unspecified`, not as universal support.
