# 来源摘要

MXMACA Runtime 仓库提供设备管理、内存分配/释放、数据传输和 kernel 启动等运行时服务的实现。本页仅记录公开仓库入口和主题范围。

## 可支持的结论

- MXMACA Runtime 与 mxcc 编译器协作为 kernel 执行提供运行时环境。
- 运行时 API 与编译器版本必须匹配。
