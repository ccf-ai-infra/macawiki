# 来源摘要

MXMACA 官方文档中心提供 GPGPU 与 MXMACA 编程模型、C++ 语言扩展、运行时 API 等主题的文档。本页仅记录公开入口和主题范围，不复制文档正文。

## 可支持的结论

- MXMACA 编程模型包含设备管理、内存操作和 kernel 启动 API。
- C++ 语言扩展提供 kernel 函数定义和调用语法。
- 运行时 API 管理设备上下文、内存分配和 kernel 启动。

## 限制

- 不提供具体 API 签名或代码示例（因版本而异）。
- 版本范围标记为 `unspecified`。
- 不能由此推断 CUDA 兼容性。
